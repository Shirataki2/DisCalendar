### サーバー設定を専用のページに分け、Webhook と API トークンを登録した人ごとに確認できるようにしました

#### Web (ブラウザ)

- カレンダー右上の歯車から開くサーバー設定を、ダイアログから専用のページに変えました。「全般」「外部カレンダー」「Webhook・API トークン」「削除した予定」に分かれているので、目的の項目をすぐに開けます。
- 「全般」で保存しても画面は閉じず、「保存しました」と表示します。保存前の変更は「変更を取り消す」で元に戻せます。保存しないまま別の項目やカレンダーへ移ろうとしたときは、変更を破棄してよいか確認します。
- 「Webhook・API トークン」に、登録した Webhook と API トークンをメンバーごとにまとめた一覧を追加しました。だれが何を登録したか、それぞれ有効か・最後にいつ使われたかを一目で確認でき、一覧から各設定の行へ移動できます。予定を作ったことがないメンバーや、サーバーから退出したメンバーが登録したものも表示します。
