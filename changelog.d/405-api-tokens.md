### サーバー用の API トークンで外部から予定を作成・更新・削除できるようにしました

#### Web (ブラウザ)

- サーバー設定に「API トークン」を追加し、名前・権限（作成のみ / 作成・更新・削除）・有効期限を指定して発行、ローテーション、失効、削除ができるようにしました。
- トークンごとの最終利用日時と直近の呼び出しログを確認できるようにしました。
- 予定の変更履歴に、API トークンで操作した履歴を「API トークン: \<名前\>」として表示するようにしました。
- 使い方ページに「API トークンで予定を登録する」を追加し、`curl` と GitHub Actions の利用例を記載しました。

#### API (サービス基盤)

- API トークンを使って `/hooks/guilds/{guild_id}/events` から予定の作成・更新・削除を行えるようにしました。
- `Idempotency-Key` ヘッダによる再送時の重複作成防止と、`external_id` による予定の更新・削除に対応しました。
