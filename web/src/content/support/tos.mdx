この利用規約 (以下「本規約」) は、DisCalendar (以下「本サービス」) の提供者 (以下「運営者」) が本サービスを提供する条件を定めるものです。本サービスを利用する方 (以下「利用者」) は、本規約に同意したうえで本サービスを利用するものとします。

## 第 1 条 (適用)

1. 本規約は、本サービスの利用に関する運営者と利用者との間の一切の関係に適用されます。
2. 運営者が本サービス上で個別に定める案内・注意書きは、本規約の一部を構成します。
3. 本サービスは Discord (Discord Inc. が提供するサービス) の機能を利用しています。利用者は本規約のほか、Discord の利用規約およびコミュニティガイドラインに従うものとします。

## 第 2 条 (定義)

本規約における用語の意味は次のとおりです。

| 用語 | 意味 |
| --- | --- |
| 本サービス | Web サイト ([https://discalendar.app](https://discalendar.app)) および Discord Bot「DisCalendar」から成る、Discord のサーバー向け予定管理サービス |
| サーバー | 本サービスの Bot が参加している Discord のサーバー (ギルド) |
| 予定 | 利用者が本サービスに登録した予定の情報 (タイトル、日時、説明、色、事前通知の設定など) |

## 第 3 条 (利用条件)

1. 本サービスの利用には Discord のアカウントが必要です。利用者は Discord アカウントで本サービスにログインすることで、本サービスを利用できます。
2. 本サービスの利用にあたって、運営者への申込みや個別の利用登録は必要ありません。
3. 利用者は、自身の Discord アカウントおよびログイン状態の管理について責任を負うものとします。

1. 予定はサーバーごとに保存され、原則として当該サーバーのメンバーであれば閲覧・作成・編集・削除ができます。
2. サーバーの設定で「編集を管理権限を持つユーザーに限定する」(restricted) を有効にした場合、予定の作成・編集・削除は当該サーバーで管理権限を持つ利用者のみが行えます。
