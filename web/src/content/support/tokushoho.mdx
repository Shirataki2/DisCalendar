この表記は、DisCalendar (以下「本サービス」) への支援 (ドネーション) の決済について、特定商取引法に基づき記載するものです。本サービス自体は無料で提供されており、支援は任意です。

| 項目 | 内容 |
| --- | --- |
| 販売事業者 | 石井 智也 |
| 運営責任者 | 同上 |
| 所在地 | 個人事業主のため省略します。請求があったら遅滞なく開示します (開示の請求は下記の連絡先まで) |
| 電話番号 | 個人事業主のため省略します。請求があったら遅滞なく開示します (開示の請求は下記の連絡先まで) |
| 連絡先 | <a href={SUPPORT_SERVER_URL} target="_blank" rel="noopener noreferrer">サポートサーバー</a> (Discord) |
| 支援金額 | 支援者が決済画面で選択または入力した金額 |
| 支援金額以外の必要料金 | なし (決済に必要な通信費は支援者の負担です) |
| 支払方法 | クレジットカードほか、決済画面 (Stripe) に表示される方法 |
| 支払時期 | 決済画面でのお手続きの完了時 |
| 提供時期 | 支援に対する個別の商品・サービスの提供はありません。本サービスは支援の有無にかかわらず同じ内容で利用できます |
| 返金・キャンセル | 支援の性質上、決済完了後の返金・キャンセルはお受けできません。誤操作や重複による決済は、上記の連絡先までご相談ください |

支援は寄付金控除など税制上の優遇の対象ではありません。
