DisCalendar の新機能や改善のお知らせを、リリースされたバージョンごとにまとめています。新しい更新が上に表示されます。

### サーバーの予定を Google カレンダーや Apple カレンダーでも見られるようになりました

#### Web (ブラウザ)

- サーバー設定 (カレンダー画面右上の歯車アイコン) に「外部カレンダーで購読する」を追加しました。管理権限を持つメンバーが「フィード URL を発行」すると、サーバーのメンバーはその URL をコピーして、Google カレンダー・Apple カレンダー・Outlook などの「URL で追加 (照会)」から購読できます。購読したカレンダーにはこのサーバーの予定 (1 年前までさかのぼった分と今後の予定) が表示され、DisCalendar での追加や変更も自動で反映されます (反映までの時間は各カレンダーサービスの更新間隔によります)
- URL を知っている人は誰でも予定を読めるので、共有する相手にはご注意ください。心配なときは「再発行」で URL を変えると古い URL は使えなくなります。「無効化」で購読自体を止めることもできます。登録のしかたは使い方の「外部カレンダーで見る」にまとめています

## v3.5.0 (2026年9月3日)

### 参加しているサーバーの予定をまとめて見られるようになりました

#### Web (ブラウザ)

- サーバー一覧の上の「すべての予定」カードか、サイドバー (スマホではメニュー) の「すべての予定」から、Bot を入れている全サーバーの予定を 1 つのカレンダーで見られるようになりました。サーバーをひとつずつ開かなくても、自分に関係する予定の全体を確かめられます
- 予定はサーバーごとの色で表示され、カレンダーの上の凡例でどのサーバーの予定か分かります。凡例のサーバー名を押すと、そのサーバーの予定を一時的に隠せます
- 予定を押すと内容とサーバー名が表示され、「このサーバーのカレンダーを開く」からそのサーバーのカレンダーに移動できます。まとめて表示する画面は見るだけで、予定の作成・編集はこれまでどおり各サーバーのカレンダーで行います

### 404 やエラーの画面を日本語にしました

#### Web (ブラウザ)

- 存在しないページを開いたときや、予期しないエラーが起きたときに、DisCalendar のデザインに合わせた日本語の案内画面を表示するようになりました。トップページやサーバー一覧へ戻るリンクと、サポートサーバーへの案内が付いています。エラーの画面には「再試行」ボタンもあります

## v3.4.0 (2026年8月31日)

### 支援ページを追加しました

#### Web (ブラウザ)

- DisCalendar の運営を任意の支援 (ドネーション) で応援できる「支援」ページを追加しました。ページ上部と下部の「支援」リンクのほか、カレンダー画面のサイドバー (スマホではメニュー) からも開けます。もちろん、これまでどおりすべての機能を無料で利用できます

## v3.3.0 (2026年8月30日)

### カレンダーに日本の祝日を表示するようになりました

#### Web (ブラウザ)

- 月表示の日付に祝日の名前 (「元日」「スポーツの日」など) が表示されるようになりました。別のカレンダーで祝日を確かめなくても、そのまま予定を入れられます
- あわせて曜日の色分けも加わりました。日曜日と祝日は赤、土曜日は青で表示されます (どの表示でも同じ色分けです)

### カレンダーの表示を好みに合わせられるようになりました

#### Web (ブラウザ)

- アカウントメニューとサイドバーに「カレンダーの表示設定」を追加しました。カレンダーを開いたとき最初に表示するビュー (月 / 週 / 4日 / 日 / リスト / 前回開いていたビュー) と、週の開始曜日 (日曜日 / 月曜日) を選べます
- 選んだ設定はテーマと同じようにこのブラウザに記憶され、次に開いたときもそのまま使われます

## v3.2.0 (2026年8月30日)

### 予定を Discord のイベントとしても作成できるようになりました

#### Web (ブラウザ)

- 予定の作成・編集画面に「Discord のイベントとしても作成する」を追加しました。チェックを入れた予定は Discord サーバーのスケジュールイベントとしても作られ、Discord 側で「興味あり」の参加表明や開始通知が使えます。予定を変更・削除すると Discord 側のイベントにも反映されます
- 利用には Bot の「イベントの作成」権限が必要です。以前から Bot を入れているサーバーでは、Bot を招待し直すと権限が付きます (詳しくは使い方の「サーバーに導入する」)
- Discord のイベントを作れるのは、あなた自身が Discord で「イベントの作成」権限を持っているサーバーだけです (連携済みの予定の編集や連携の解除は、これまでどおり予定を編集できる人なら誰でもできます)
- 権限が足りないという案内の下に「権限を再確認」ボタンを用意しました。Bot を招待し直したり、ロールに権限を付けてもらったあとにこれを押すと、待たずにその場で使えるようになります

#### Bot (Discord)

- 招待リンクで求める権限に「イベントの作成」を追加しました

## v3.1.0 (2026年8月28日)

### 更新履歴にバージョンを表示するようにしました

#### Web (ブラウザ)

- この更新履歴を「v3.0.2 (2026年8月28日)」のようにリリースごとにまとめて表示するようにしました。カレンダー画面の下部に表示されているバージョンで、どんな変更が入ったのかを確認しやすくなります

### 予定を一覧で見られる「リスト」表示を追加しました

#### Web (ブラウザ)

- カレンダー右上の表示の切り替えに「リスト」を追加しました。その月の予定が日付順に並び、予定のある日だけが表示されるので、セルの小さいスマートフォンでも先の予定を順に確認できます。予定をタップすると、これまでと同じ内容の画面が開きます

### 予定を複製できるようにしました

#### Web (ブラウザ)

- 予定をクリックして表示される画面に「複製」ボタンを追加しました。元の予定のタイトル・説明・時刻・通知の設定が入った状態で作成画面が開くので、日付だけ変えて似た予定をすばやく作れます

### 利用状況の記録を始めました

#### Web (ブラウザ)

- サービスの改善に役立てるため、ログイン中の利用者が DisCalendar を使った日の記録を始めました。記録するのは利用者の ID と日付の組だけで、IP アドレスや操作の内容は含みません。詳しくはプライバシーポリシーをご覧ください

## v3.0.2 (2026年8月28日)

### 画面が表示できないときのご案内を分かりやすくしました

#### Web (ブラウザ)

- 何らかの不具合で画面を表示できなかったときに、英語のメッセージではなく日本語のご案内と「再読み込み」ボタンを表示するようにしました
- 不具合が起きたときの記録が運営者に届くようにしました。原因の調査と修正に役立てます (記録する内容はプライバシーポリシーをご覧ください)

## v3.0.0 (2026年8月27日)

### サイトのアイコンとリンク共有時の画像を一新しました

#### Web (ブラウザ)

- ブラウザのタブやスマートフォンのホーム画面に表示されるアイコンのデザインを新しくしました
- Discord や X に DisCalendar のリンクを貼ったときに表示される画像を新しくしました

### Bot を招待したあと、そのサーバーのカレンダーがすぐ開くようにしました

#### Web (ブラウザ)

- サーバー選択画面から Bot を招待し、Discord のタブを閉じて戻ってくると、そのサーバーのカレンダーを自動で開くようにしました。これまでは画面を読み込み直すまで「Bot を招待できるサーバー」に並んだままでした

### カレンダー画面を明るい配色に切り替えられるようにしました

#### Web (ブラウザ)

- カレンダー画面 (サーバー一覧・予定の画面) の配色を、暗い色 (ダーク) と明るい色 (ライト) から選べるようにしました。左のメニューか右上のアカウントメニューの「ライトテーマに切り替え」から変更できます
- 選んだ配色はこのブラウザに記憶され、次に開いたときもそのまま表示されます

### ログイン画面から他のページへ移動できるようにしました

#### Web (ブラウザ)

- ログイン画面にも他のページと同じヘッダとフッタを表示しました。ログインしないまま、トップページ・[使い方](/docs/gettingstarted)・[更新履歴](/changelog)・[利用規約](/support/tos)・[プライバシーポリシー](/support/privacy)・サポートサーバーへ移動できます
- ログアウトしたあとはトップページに戻るようにしました

### カレンダーの日付と時刻の表示を整えました

#### Web (ブラウザ)

- 予定の時刻を「2:00」の形に統一しました。これまではお使いのブラウザによって「2時」「2時00分〜3時00分」のように表示が変わることがありました
- 日付の表示から「日」を省きました。月表示のマス目は「25」、週・4日・1日表示の見出しは「25(火)」のように表示されます

### DisCalendar を全面リニューアル

DisCalendar を土台から作り直し、デザイン・操作性・速度を全面的に見直しました。
保存されている予定やサーバーの設定はそのまま引き継がれるため、利用者のみなさまの移行作業は必要ありません。

#### Web (ブラウザ)

- 画面デザインを全面的に刷新しました。カレンダーやダイアログの配色・レイアウトを見直し、より見やすく操作しやすくなりました
- スマートフォンでの操作性を改善しました。カレンダーの日付をタップするだけで、その日の予定の作成を始められます
- ホーム画面への追加 (PWA) に対応しました。スマートフォンやタブレットで、アプリのように起動できます
- ページの表示速度を改善しました
- [使い方](/docs/gettingstarted)・[利用規約](/support/tos)・[プライバシーポリシー](/support/privacy) の各ページも新しいデザインになりました

#### Bot (Discord)

- コマンドをスラッシュコマンド (`/help`, `/create`, `/list`, `/init`, `/invite`) に一本化しました。入力中にコマンドの説明や入力候補が表示されます
- これに伴い、`cal` から始まる旧形式のコマンドは廃止しました
- 予定の事前通知など、通知はこれまでどおり設定したチャンネルに届きます

#### API (サービス基盤)

- 応答速度と安定性を向上しました
- 予定・サーバー・通知の設定のデータは、そのまま引き継がれます
