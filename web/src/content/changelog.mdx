DisCalendar の新機能や改善のお知らせをまとめています。新しい更新が上に表示されます。

## 2026年8月28日 — 予定を一覧で見られる「リスト」表示を追加しました

### Web (ブラウザ)

- カレンダー右上の表示の切り替えに「リスト」を追加しました。その月の予定が日付順に並び、予定のある日だけが表示されるので、セルの小さいスマートフォンでも先の予定を順に確認できます。予定をタップすると、これまでと同じ内容の画面が開きます

## 2026年8月28日 — 予定を複製できるようにしました

### Web (ブラウザ)

- 予定をクリックして表示される画面に「複製」ボタンを追加しました。元の予定のタイトル・説明・時刻・通知の設定が入った状態で作成画面が開くので、日付だけ変えて似た予定をすばやく作れます

## 2026年8月28日 — 利用状況の記録を始めました

### Web (ブラウザ)

- サービスの改善に役立てるため、ログイン中の利用者が DisCalendar を使った日の記録を始めました。記録するのは利用者の ID と日付の組だけで、IP アドレスや操作の内容は含みません。詳しくはプライバシーポリシーをご覧ください

## 2026年8月27日 — 画面が表示できないときのご案内を分かりやすくしました

### Web (ブラウザ)

- 何らかの不具合で画面を表示できなかったときに、英語のメッセージではなく日本語のご案内と「再読み込み」ボタンを表示するようにしました
- 不具合が起きたときの記録が運営者に届くようにしました。原因の調査と修正に役立てます (記録する内容はプライバシーポリシーをご覧ください)

## 2026年8月26日 — サイトのアイコンとリンク共有時の画像を一新しました

### Web (ブラウザ)

- ブラウザのタブやスマートフォンのホーム画面に表示されるアイコンのデザインを新しくしました
- Discord や X に DisCalendar のリンクを貼ったときに表示される画像を新しくしました

## 2026年8月26日 — Bot を招待したあと、そのサーバーのカレンダーがすぐ開くようにしました

### Web (ブラウザ)

- サーバー選択画面から Bot を招待し、Discord のタブを閉じて戻ってくると、そのサーバーのカレンダーを自動で開くようにしました。これまでは画面を読み込み直すまで「Bot を招待できるサーバー」に並んだままでした

## 2026年8月26日 — カレンダー画面を明るい配色に切り替えられるようにしました

### Web (ブラウザ)

- カレンダー画面 (サーバー一覧・予定の画面) の配色を、暗い色 (ダーク) と明るい色 (ライト) から選べるようにしました。左のメニューか右上のアカウントメニューの「ライトテーマに切り替え」から変更できます
- 選んだ配色はこのブラウザに記憶され、次に開いたときもそのまま表示されます

## 2026年8月25日 — ログイン画面から他のページへ移動できるようにしました

### Web (ブラウザ)

- ログイン画面にも他のページと同じヘッダとフッタを表示しました。ログインしないまま、トップページ・[使い方](/docs/gettingstarted)・[更新履歴](/changelog)・[利用規約](/support/tos)・[プライバシーポリシー](/support/privacy)・サポートサーバーへ移動できます
- ログアウトしたあとはトップページに戻るようにしました

## 2026年8月25日 — カレンダーの日付と時刻の表示を整えました

### Web (ブラウザ)

- 予定の時刻を「2:00」の形に統一しました。これまではお使いのブラウザによって「2時」「2時00分〜3時00分」のように表示が変わることがありました
- 日付の表示から「日」を省きました。月表示のマス目は「25」、週・4日・1日表示の見出しは「25(火)」のように表示されます

## 2026年8月24日 — DisCalendar を全面リニューアル

DisCalendar を土台から作り直し、デザイン・操作性・速度を全面的に見直しました。
保存されている予定やサーバーの設定はそのまま引き継がれるため、利用者のみなさまの移行作業は必要ありません。

### Web (ブラウザ)

- 画面デザインを全面的に刷新しました。カレンダーやダイアログの配色・レイアウトを見直し、より見やすく操作しやすくなりました
- スマートフォンでの操作性を改善しました。カレンダーの日付をタップするだけで、その日の予定の作成を始められます
- ホーム画面への追加 (PWA) に対応しました。スマートフォンやタブレットで、アプリのように起動できます
- ページの表示速度を改善しました
- [使い方](/docs/gettingstarted)・[利用規約](/support/tos)・[プライバシーポリシー](/support/privacy) の各ページも新しいデザインになりました

### Bot (Discord)

- コマンドをスラッシュコマンド (`/help`, `/create`, `/list`, `/init`, `/invite`) に一本化しました。入力中にコマンドの説明や入力候補が表示されます
- これに伴い、`cal` から始まる旧形式のコマンドは廃止しました
- 予定の事前通知など、通知はこれまでどおり設定したチャンネルに届きます

### API (サービス基盤)

- 応答速度と安定性を向上しました
- 予定・サーバー・通知の設定のデータは、そのまま引き継がれます
