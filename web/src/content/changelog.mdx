DisCalendar の新機能や改善のお知らせをまとめています。新しい更新が上に表示されます。

## 2026年8月25日 — カレンダーの日付と時刻の表示を整えました

### Web (ブラウザ)

- 予定の時刻を「2:00」の形に統一しました。これまではお使いのブラウザによって「2時」「2時00分〜3時00分」のように表示が変わることがありました
- 日付の表示から「日」を省きました。月表示のマス目は「25」、週・4日・1日表示の見出しは「25(火)」のように表示されます

## 2026年8月24日 — DisCalendar を全面リニューアル

DisCalendar を土台から作り直し、デザイン・操作性・速度を全面的に見直しました。
保存されている予定やサーバーの設定はそのまま引き継がれるため、利用者のみなさまの移行作業は必要ありません。

### Web (ブラウザ)

- 画面デザインを全面的に刷新しました。カレンダーやダイアログの配色・レイアウトを見直し、より見やすく操作しやすくなりました
- スマートフォンでの操作性を改善しました。カレンダーの日付をタップするだけで、その日の予定の作成を始められます
- ホーム画面への追加 (PWA) に対応しました。スマートフォンやタブレットで、アプリのように起動できます
- ページの表示速度を改善しました
- [使い方](/docs/gettingstarted)・[利用規約](/support/tos)・[プライバシーポリシー](/support/privacy) の各ページも新しいデザインになりました

### Bot (Discord)

- コマンドをスラッシュコマンド (`/help`, `/create`, `/list`, `/init`, `/invite`) に一本化しました。入力中にコマンドの説明や入力候補が表示されます
- これに伴い、`cal` から始まる旧形式のコマンドは廃止しました
- 予定の事前通知など、通知はこれまでどおり設定したチャンネルに届きます

### API (サービス基盤)

- 応答速度と安定性を向上しました
- 予定・サーバー・通知の設定のデータは、そのまま引き継がれます
