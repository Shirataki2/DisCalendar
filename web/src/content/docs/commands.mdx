DisCalendar の Bot は、Discord のスラッシュコマンドから次の操作ができます。
入力欄で `/` を打つとコマンドの候補と引数の説明が表示されます。
メッセージの右クリック（スマホでは長押し）から使える「予定にする」もあります。

<Callout>
旧版で使えた `cal help` のような「cal」で始まるコマンドは廃止されました。すべてスラッシュコマンドに置き換わっています。
</Callout>

<CommandCard name="/help">
DisCalendar の使い方と Bot の招待リンクを埋め込みで表示します。返信は実行した本人にだけ見えます。
</CommandCard>

<CommandCard name="/init" args="[チャンネル]" permission="管理権限が必要">
予定の通知を投稿するチャンネルを設定します。`チャンネル` を省略するとコマンドを実行したチャンネルが通知先になります。
もう一度実行すると通知先を変更できます。

指定したチャンネルで Bot に「チャンネルを見る」「メッセージを送信」「埋め込みリンク」の権限が無い場合は保存されず、足りない権限が返信されます。
くわしくは [初期設定](/docs/initialize) を見てください。
</CommandCard>

<CommandCard name="/create" args="名称 開始… 終了… [説明] [場所 / URL] [終日] [色] [通知…]" permission="restricted モードでは管理権限または指定ロールが必要">
ブラウザを開かずに予定を作成します。作った予定はそのままカレンダー画面にも表示されます。

- 必須: 予定の名称 (32 文字まで)、開始日時と終了日時 (年・月・日・時・分をそれぞれ入力)
- 任意: 説明 (1000 文字まで)、場所 / URL (200 文字まで)、終日 (時・分は無視されます)、色 (赤 / 青 / 緑 / 黄 / 紫 / 水色 / 橙 / ピンク / 灰 / 黒。省略時は青)、事前通知 (5 分前〜7 日前の候補から 4 つまで)

存在しない日付や、終了が開始より前の指定はエラーになります。
サーバー設定で予定の編集が制限されているときは、管理権限または「編集を許可するロール」に指定されたロールが必要です。
</CommandCard>

## メッセージから予定を作成する

1. 予定の相談をしたメッセージを右クリック（スマホでは長押し）し、「アプリ」→「予定にする」を選びます。
2. 入力画面でタイトル・日付・開始時刻・所要時間を確認・修正します。空欄は手入力してください。
3. 送信後に表示される開始・終了日時を確認し、2 分以内に「作成する」を押します。

たとえば「土曜 21時から2時間集まろう」から日付・開始時刻・所要時間の候補を読み取ります。
日時は日本時間（JST）です。「今日」「明日」はコマンドを実行した日が基準になり、
曜日は当日を含む次の該当日を使います。古いメッセージから作る場合も、候補の日付を必ず確認してください。

- 日付の候補: `今日`、`明日`、`土曜`・`土曜日` などの曜日、`YYYY-MM-DD`
- 時刻の候補: `21時`、`21時30分`、`21時半`、`21:00`（全角の数字・コロンにも対応）
- 所要時間の候補: `2時間`、`30分`、`1時間30分`。入力画面では 1〜10080 分の整数で指定します。
- タイトルの候補: 本文の最初の空でない行を 32 文字まで表示します。

読み取れない項目や複数の候補がある項目は空欄になります。日付の手入力は `YYYY-MM-DD`・`今日`・`明日`、
時刻は `HH:mm` を使います。入力画面は 5 分以内に送信してください。キャンセルや時間切れでは保存しません。

確認と結果、エラーの返信は本人だけに表示されます。作成結果のタイトルからカレンダーを開けます。
予定の説明には元メッセージへのリンクが入り、本文は転載しません。リンク先は Discord でそのチャンネルを閲覧できる人だけが開けます。
予定の色は青、事前通知はなし（開始時の通知はサーバー設定に従います）。
restricted モードでは `/create` と同じ管理権限または編集ロールが必要で、保存時に確認します。

## その他のコマンド

<CommandCard name="/list" args="[範囲]">
予定の一覧を表示します。`範囲` は `未来` (既定) / `過去` / `全て` から選べます。
4 件ずつ表示され、「前へ」「次へ」のボタンでページを送り、「完了」で一覧を閉じます。
ブラウザから作った予定も表示されます。

</CommandCard>

## 管理権限について

「管理権限」は、サーバーで **管理者**、**サーバー管理**、**メッセージの管理**、**ロールの管理** のいずれかの権限を持っていること (またはサーバーのオーナーであること) を指します。
サーバー設定や `/init` にはこの管理権限が必要です。予定の編集と `/create` は、restricted モードでも「編集を許可するロール」を持つメンバーが使えます。
