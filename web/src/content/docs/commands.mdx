DisCalendar の Bot は、Discord のスラッシュコマンドから次の操作ができます。
入力欄で `/` を打つとコマンドの候補と引数の説明が表示されます。

<Callout>
旧版で使えた `cal help` のような「cal」で始まるコマンドは廃止されました。すべてスラッシュコマンドに置き換わっています。
</Callout>

<CommandCard name="/help">
DisCalendar の使い方と Bot の招待リンクを埋め込みで表示します。返信は実行した本人にだけ見えます。
</CommandCard>

<CommandCard name="/init" args="[チャンネル]" permission="管理権限が必要">
予定の通知を投稿するチャンネルを設定します。`チャンネル` を省略するとコマンドを実行したチャンネルが通知先になります。
もう一度実行すると通知先を変更できます。

指定したチャンネルで Bot に「チャンネルを見る」「メッセージを送信」「埋め込みリンク」の権限が無い場合は保存されず、足りない権限が返信されます。
くわしくは [初期設定](/docs/initialize) を見てください。
</CommandCard>

<CommandCard name="/create" args="名称 開始… 終了… [説明] [終日] [色] [通知…]" permission="restricted モードでは管理権限が必要">
ブラウザを開かずに予定を作成します。作った予定はそのままカレンダー画面にも表示されます。

- 必須: 予定の名称 (32 文字まで)、開始日時と終了日時 (年・月・日・時・分をそれぞれ入力)
- 任意: 説明 (1000 文字まで)、終日 (時・分は無視されます)、色 (赤 / 青 / 緑 / 黄 / 紫 / 水色 / 橙 / ピンク / 灰 / 黒。省略時は青)、事前通知 (5 分前〜7 日前の候補から 4 つまで)

存在しない日付や、終了が開始より前の指定はエラーになります。
サーバー設定で予定の編集が管理権限を持つユーザーに限定されているときは、権限の無いメンバーは実行できません。
</CommandCard>

<CommandCard name="/list" args="[範囲]">
予定の一覧を表示します。`範囲` は `未来` (既定) / `過去` / `全て` から選べます。
4 件ずつ表示され、「前へ」「次へ」のボタンでページを送り、「完了」で一覧を閉じます。
ブラウザから作った予定も表示されます。
</CommandCard>

<CommandCard name="/invite">
Bot をほかのサーバーにも追加するための招待リンクを表示します。
</CommandCard>

## 管理権限について

「管理権限」は、サーバーで **管理者**、**サーバー管理**、**メッセージの管理**、**ロールの管理** のいずれかの権限を持っていること (またはサーバーのオーナーであること) を指します。
ブラウザのサーバー設定 (restricted モード) でも同じ判定を使っています。
