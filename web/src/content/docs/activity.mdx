## Discord の中でカレンダーを開く

DisCalendar は Discord の **アクティビティ** に対応しています。ブラウザに切り替えなくても、Discord の中でそのサーバーのカレンダーを開けます。
ボイスチャンネルで集まって次の予定を相談するときなどに使えます。

1. DisCalendar の Bot が参加しているサーバーで、ボイスチャンネルまたはテキストチャンネルを開きます
2. 入力欄やボイスチャンネルの **アクティビティ** (ロケットのアイコン) から **DisCalendar** を選びます
3. 初めて使うときは、Discord アカウントでのログインを求める画面が出るので **認証** を押します

起動したサーバーのカレンダーが開きます。ほかのサーバーのカレンダーを見るときは、そのサーバーからアクティビティを起動してください。

## できること

予定の表示・作成・編集・削除は、ブラウザで開いたときと同じです。編集できる人の制限 ([予定の編集と削除](/docs/edit)) もそのまま適用されます。

使い方のページや共有リンクなど、アクティビティの外のページへのリンクを押すと、Discord の確認を挟んでブラウザで開きます。
日程調整・すべての予定・サーバーの切り替えは、ブラウザの DisCalendar から使ってください。

<Callout type="info">
同じアクティビティに参加している人どうしで、画面の動きは同期しません。それぞれの画面で予定を操作し、保存した内容は再読み込みで反映されます。
</Callout>

## 開けないとき

- 「サーバーデータの取得に失敗しました」と出る場合は、Bot がサーバーに導入されているか、あなたがそのサーバーのメンバーかを確認してください
- DM やグループ DM ではカレンダーを開けません。サーバーのチャンネルから起動してください
- 「ログインできませんでした」と出る場合は、アクティビティを開き直してください。続く場合はブラウザから DisCalendar を開いてください
- 添付ファイルのアップロードなど、一部の操作は Discord の制限で動かないことがあります。その場合はブラウザから操作してください
