Bot を追加したら、予定の通知をどのチャンネルに投稿するかを決めます。
この設定をしないと、カレンダーに予定を追加しても通知は届きません。

通知先は、ブラウザのサーバー設定から選べます。Discord の `/init` も代わりに利用でき、どちらから変更しても同じ設定に反映されます。

## ブラウザのサーバー設定から設定する

[ログイン](/docs/login) してサーバーのカレンダーを開き、右上の歯車アイコン (サーバー設定) を押すと「Discord への通知」の項目があります。

- **通知先チャンネル**: 一覧から通知を投稿するチャンネルを選びます。Bot に「チャンネルを見る」「メッセージを送信」「埋め込みリンク」の権限が無いチャンネルは選べず、足りない権限が表示されます
- **開始時刻に通知する**: 外すと、予定ごとに設定した事前通知だけが届きます (終日予定の 0:00 の通知も届きません)
- **既定の事前通知**: このサーバーで予定を新しく作るときの「通知」欄の初期値です (最初は「1 日前」と「1 時間前」)。予定ごとに変更できます

各項目の ⓘ アイコンにカーソルを合わせるか、キーボードでフォーカスすると補足を確認できます。スマートフォンではタップして表示します。

「保存」を押すと反映されます。設定を変更できるのは、下の「実行できる人」と同じ権限を持つ人です。

## Discord の /init で設定する

通知を受け取りたいチャンネルで、次のスラッシュコマンドを実行します。

```
/init
```

別のチャンネルを通知先にしたいときは、`チャンネル` オプションで指定できます。

```
/init チャンネル: #予定の通知
```

成功すると、Bot が「イベント通知を有効にしました」と通知先のチャンネルを返信します (すでに設定済みのサーバーでは「イベント通知先を変更しました」)。
これで Discord 側の初期設定は完了です。あとは [カレンダーページで予定を追加](/docs/calendar) すれば、
予定の開始時刻と設定した事前通知の時刻に Discord へ通知が届きます。

通知の日時は各自の Discord の言語・タイムゾーン設定で表示され、開始までの残り時間も確認できます。
終日予定は登録された日付のまま表示されます。
通知のタイトルや「カレンダーで開く」を押すと、そのサーバーのカレンダーへ移動できます (未ログインの場合はログイン後に同じカレンダーへ戻ります)。
共有リンクを発行済みの予定には「詳細を見る」も表示され、ログインせずに予定を確認できます。

## 予定のまとめを投稿する

サーバー設定の「予定のまとめを投稿する」で、Bot が通知先チャンネルへ予定の一覧を自動投稿できます。変更にはサーバーの管理権限が必要です。
先に「通知先チャンネル」を選んで「保存」するか、Discord の `/init` で通知先を設定してください。

- **毎日、今日の予定を投稿する**: その日の予定をまとめます。既定の時刻は **8:00 (JST)** です
- **毎週、今週の予定を投稿する**: 選んだ曜日から **7日間** の予定をまとめます。既定は **月曜 8:00 (JST)** です
- **予定が無い日は投稿しない**: 最初は有効です。毎週の投稿では7日間の予定が無い場合に省略します。外すと「今日の予定はありません」「今週の予定はありません」と投稿します

最初は毎日・毎週とも無効です。時刻・曜日を選び、**「まとめ投稿を保存」** を押すと反映されます。この節はダイアログ下の「保存」「キャンセル」とは別に保存します。
投稿時刻は、カレンダーの表示タイムゾーンに関係なく日本時間 (JST) です。

日付をまたぐ予定・終日予定・繰り返し予定も対象です。予定の日時は Discord の表示設定に合わせて表示され、終日予定は日付で表示されます。
予定が多い場合は表示できる先頭の予定と「ほか N 件」を投稿し、カレンダーへのリンクから全件を確認できます。

Bot が停止していた場合は、復帰した日の投稿時刻を過ぎていれば、その日の未投稿分を投稿します。毎週の投稿は選んだ曜日のみで、前日以前の分は遡りません。
通知先の削除・権限不足などで投稿できなかった分は、その日は再送しません。通知先と Bot の権限を確認してください。

## 実行できる人

`/init` の実行とサーバー設定の変更ができるのは、サーバーで次のいずれかの権限を持っている人か、サーバーのオーナーです。

- 管理者
- サーバー管理
- メッセージの管理
- ロールの管理

権限が無い場合は、その旨の返信が本人にだけ表示されます。

## うまくいかないとき

<Callout type="warning" title="Bot 側の権限が足りない">
指定したチャンネルで Bot に「チャンネルを見る」「メッセージを送信」「埋め込みリンク」の権限が無いと、設定は保存されず、足りない権限が返信で表示されます。
チャンネルの権限設定で Bot に権限を与えてから、もう一度 `/init` を実行してください ([Bot の招待](/docs/invite) の「Bot に必要な権限」)。
</Callout>

<Callout>
- 通知先は `/init` を実行し直すか、サーバー設定で選び直すといつでも変更できます (最後に設定したチャンネルが通知先になります)
- 入力欄に `/init` の候補が出ないときは、Bot を追加した直後で Discord 側にコマンドが反映されていない可能性があります。しばらく待つか、Discord を再起動してみてください
- 旧版にあった `cal init` などの「cal」で始まるコマンドは使えなくなりました。スラッシュコマンドを使ってください
</Callout>
