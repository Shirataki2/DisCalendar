[ログイン](/docs/login) してサーバー一覧から Bot を追加したサーバーを選ぶと、そのサーバーのカレンダー画面が開きます。
カレンダーはサーバーのメンバー全員で共有され、だれかが追加・変更した予定はほかのメンバーの画面にも同じように表示されます。

## カレンダー画面の見方

<Screenshot src={calendarShot} alt="カレンダー画面。上部に「新規作成」ボタンと月の切り替え、月表示に色分けされた予定が並んでいる" />

- **前へ / 次へ / 今日**: 表示する期間を動かします。「今日」を押すと、どの月を見ていても今日を含む期間に戻ります
- **月 / 週 / 4日 / 日 / リスト**: 表示の単位を切り替えます。週・4日・日の表示では時間ごとの枠に予定が並び、現在時刻に赤い線が引かれます。「リスト」はその月の予定を日付順に並べた一覧で、予定のある日だけが表示されます
- **新規作成**: 予定の作成ダイアログを開きます
- 右上の **サーバー名の横の歯車**: サーバー設定を開きます ([予定の編集と削除](/docs/edit) の「編集できる人を制限する」)

カレンダーを開いたとき **最初に表示するビュー** (前回開いていたビューのままにもできます) と **週の開始曜日** (日曜 / 月曜) は、
アカウントメニューまたはサイドバーの **「カレンダーの表示設定」** で変えられます。設定はお使いのブラウザに記憶されます。

## すべてのサーバーの予定をまとめて見る

複数のサーバーで DisCalendar を使っている場合は、サーバー一覧の上の **「すべての予定」** カード、またはサイドバー
(スマートフォンではメニュー) の **「すべての予定」** から、Bot を入れている全サーバーの予定を 1 つのカレンダーで見られます。

- 予定は **サーバーごとの色** で表示され、カレンダーの上の凡例でどのサーバーの予定か分かります (サーバーが 10 を超えると同じ色が使い回されます)
- 凡例のサーバー名を押すと、そのサーバーの予定を一時的に隠せます (もう一度押すと戻ります。この設定は記憶されません)
- 予定を押すと内容とサーバー名が表示され、**「このサーバーのカレンダーを開く」** からそのサーバーのカレンダーに移動できます

この画面は見るだけです。予定の作成・編集・削除は、それぞれのサーバーのカレンダーで行ってください。
表示される予定は、あなたがメンバーとして参加しているサーバーのものだけです (各サーバーのカレンダーで見られる範囲と同じです)。

## 予定を作成する

次のどちらかの操作で予定の作成ダイアログが開きます。

- 左上の **「新規作成」** ボタンを押す
- カレンダーの **日付や時間帯をクリック** する (週・4日・日の表示ではドラッグで範囲を選ぶと、その時間帯が開始・終了に入った状態で開きます。スマートフォンでは長押しします)

<Screenshot src={createDialogShot} alt="予定の作成ダイアログ。タイトル、開始日・開始時刻、終日、終了日・終了時刻、色、通知、説明の入力欄と「Discord のイベントとしても作成する」のチェックがある" size="narrow" />

| 項目 | 内容 |
|---|---|
| タイトル (必須) | 予定の名前。32 文字まで |
| 開始日 / 開始時刻、終了日 / 終了時刻 | 予定の期間。開始日を終了日より後の日にすると終了日も同じ日に合わせます (時刻は自動では変わりません)。終了日時が開始日時より前のままだと保存時にエラーになります |
| 終日 | チェックすると時刻の入力が消え、日付だけの予定になります |
| 色 | カレンダー上の予定の色。候補の色から選ぶか、「その他の色」で自由に指定できます |
| 通知 | 事前通知のタイミング。「30 分前」「1 日前」のように数値と単位 (分前 / 時間前 / 日前 / 週間前) を指定します。「通知を追加」で最大 10 件まで設定できます |
| 説明 | 補足のメモ。1000 文字まで。通知のメッセージにも載ります |
| Discord のイベントとしても作成する | チェックすると、Discord のスケジュールイベントも一緒に作られます (下の「Discord のイベントとしても作成する」) |

「作成」を押すとカレンダーに予定が追加されます。

### Discord のイベントとしても作成する

チェックを入れて作成した予定は、Discord サーバーの **スケジュールイベント** としても作られます。
Discord 側では「興味あり」で参加表明ができ、開始時にはイベントの通知も届きます。
その後にカレンダーで予定を変更・削除すると、Discord 側のイベントにも反映されます。

次の場合はチェックできません (理由がチェックの下に表示されます)。

- **あなたに Discord の「イベントの作成」権限が無い** — Discord のイベントは、Discord 上でイベントを作れる人だけが作れます。サーバーの管理者にロールの権限を確認してください
- Bot にサーバーの **「イベントの作成」権限が無い** — 以前から Bot を入れているサーバーでは、[招待し直す](/docs/invite) と権限が付きます
- **開始日時が過去** — Discord のイベントは未来の開始時刻でしか作れません

権限が足りないときは、案内の下に **「権限を再確認」** ボタンが出ます。
Bot を招待し直したり、ロールに権限を付けてもらったあとにこれを押すと、その場で使えるようになります
(押さない場合は、しばらくしてからページを開き直すと反映されます)。

なお、連携済みの予定の内容を変えたり、チェックを外して連携をやめたりするのは、
カレンダーの予定を編集できる人なら誰でもできます (制限されるのは新しく連携させるときだけです)。

<Callout>
Discord 側でイベントを直接編集・削除しても、カレンダーの予定には反映されません (カレンダー側を変更すると、Discord 側は改めて上書き・作り直しされます)。
</Callout>

### 通知について

予定の **開始時刻** と、通知欄で設定した **それぞれのタイミング** に、Bot が `/init` で設定したチャンネルへ埋め込みメッセージを投稿します。
通知を 1 件も設定しなくても、開始時刻の通知は届きます。

<Callout type="warning">
通知を受け取るには、あらかじめサーバーで `/init` を実行して通知先チャンネルを設定しておく必要があります ([初期設定](/docs/initialize))。
</Callout>

<Callout>
サーバー設定で「予定の編集を管理権限を持つユーザーに限定する」(restricted モード) が有効になっているサーバーでは、
権限の無いメンバーは予定を見ることはできますが、作成・編集・削除はできません。そのときは「新規作成」ボタンが押せなくなり、画面上部に案内が表示されます。
</Callout>

## Discord から予定を作る

ブラウザを開かなくても、Discord の `/create` コマンドから同じカレンダーに予定を追加できます。
くわしくは [利用可能なコマンド](/docs/commands) を見てください。
