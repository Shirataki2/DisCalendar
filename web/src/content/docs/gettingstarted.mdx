DisCalendar は、Discord のサーバーごとに共有カレンダーを持てるサービスです。
予定はブラウザのカレンダー画面から追加・編集でき、開始時刻や設定した事前通知のタイミングになると Bot が Discord のチャンネルへ通知を投稿します。

## 導入前に操作を試す

ログインや Bot の導入、予定の編集権限がなくても、練習用カレンダーで操作を体験できます。
案内に沿って予定を作成・編集し、Discord に届く通知の見本を確認して、削除まで試してみましょう。

<LinkButton href={ROUTES.tutorial} variant="primary">操作を試す</LinkButton>

案内はいつでも終了して自由に操作できます。「最初からやり直す」で案内と予定を初期状態に戻せます。
練習用の予定は保存されず、ページを開き直すとリセットされます。実際のサーバーへの保存や Discord への通知は行いません。

## 導入までの 3 ステップ

<Steps>
  <Step title="Bot をサーバーに招待する">
    通知を届けるために、まず DisCalendar の Bot を Discord のサーバーに追加します。
    追加できるのはそのサーバーの「管理者」か「サーバー管理」の権限を持っている人です。

    <LinkButton href={ROUTES.invite} variant="primary" external>Bot を招待する</LinkButton>

    くわしくは [Bot の招待](/docs/invite) を見てください。
  </Step>
  <Step title="Web のサーバー設定で通知先を決める">
    Discord アカウントで [ログイン](/docs/login) し、サーバーのカレンダーを開きます。右上の歯車アイコン (サーバー設定) の「通知先チャンネル」から、Bot の通知を投稿するチャンネルを選んで保存します。

    Discord 側で設定したい場合は、代わりに通知を受け取りたいチャンネルでスラッシュコマンドを実行できます。

    ```
    /init
    ```

    どちらも「管理者」「サーバー管理」「メッセージの管理」「ロールの管理」のいずれかの権限を持っている人 (またはサーバーのオーナー) が行えます。
    くわしくは [初期設定](/docs/initialize) を見てください。
  </Step>
  <Step title="ブラウザで予定を追加する">
    サーバー一覧から Bot を追加したサーバーを選んでカレンダーを開き、日付をクリックするか「新規作成」ボタンから予定を作ってみましょう。

    予定の開始時刻と、🔔 で設定した事前通知の時刻になると、Discord のチャンネルに自動でメッセージが届きます。
    通知の日時は各自の Discord の言語・タイムゾーン設定で表示されます (終日予定の日付は変わりません)。
    通知の「カレンダーで開く」からサーバーのカレンダーへ移動できます。
    予定をクリックすると編集や削除ができます。

    <LinkButton href={ROUTES.dashboard}>サーバー一覧を開く</LinkButton>
  </Step>
</Steps>

## 困ったときは

動かない・分からないことがあれば、サポートサーバーの「#不具合報告」チャンネルで知らせてください。
