Sign in with your Discord account to view and create events in your browser.

## Sign in

1. Select **Sign in** in the header or open the page below.
2. Select **Sign in with Discord** to open Discord's authorization screen.
3. Review and authorize access. You will return to the server list.

<LinkButton href={ROUTES.login} variant="primary">Open sign-in page</LinkButton>

<Screenshot src={loginShot} alt="DisCalendar sign-in page with a Discord sign-in button (Japanese interface)." />

Discord asks for access to:

- **Username, avatar, and email address** (`identify` / `email`): identifies you and displays your name and avatar.
- **Your server list** (`guilds`): shows servers whose calendars you can open and servers you can invite the bot to.

<Callout>
This information is only used to identify you and your servers. See the [Privacy Policy](/support/privacy) (Japanese).
</Callout>

## Change the display language

Choose **日本語 / English** in the header, before or after signing in. On your first visit, an English browser language selects English; other languages select Japanese. Your choice is saved in this browser and shared across reloads and tabs. If browser storage is unavailable, the choice applies only to the current tab. It does not sync across browsers or devices.

The calendar, event operations, personal and server settings, push notification settings, public shared events, scheduling polls, ICS imports, integrations, MCP connection screens, tutorial, homepage, and guides support both languages. Missing translations fall back to Japanese. Legal pages, the Privacy Policy, and past release notes remain in Japanese. Screenshots show the Japanese interface.

Changing the website language does not change bot replies, notification bodies, or posts sent to integrations. Event titles, descriptions, server names, saved dates, all-day ranges, reminder timing, first day of the week, and permissions are unchanged. Event times remain in Japan Standard Time (JST).

## After signing in

The server list is at `/dashboard`. Your Discord avatar and name appear in the header. Open the avatar menu to return to the server list or sign out. The menu button opens links to the homepage, guides, terms, and support server.

<Screenshot src={serverSelectShot} alt="Server list with a practice-calendar banner, All events card, joined servers, and servers where the bot can be invited (Japanese interface)." />

- Select a server that already has the bot to [open its calendar](/docs/calendar).
- Add the bot to other servers under **Servers you can invite the bot to**; see [Invite the bot](/docs/invite).

<LinkButton href={ROUTES.dashboard}>Open server list</LinkButton>

## If sign-in fails

If authorization fails or does not return you to the website, try another browser. If the problem continues, report it in **#不具合報告** on the support server.
