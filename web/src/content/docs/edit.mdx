作成した予定は、カレンダー上の予定をクリック (スマートフォンではタップ) すると編集・削除できます。

## 予定の内容を見る

予定をクリックすると、タイトル・日時・通知・場所・説明と、予定を作成した人が表示されます。場所が URL の場合は、そのままリンクとして開けます。
編集された予定には、最後に更新した人と更新日時も表示されます。サーバーを退出した人は「退出したメンバー」、記録を開始する前に作られた予定は「記録なし」と表示されます。
参加しているサーバーの予定をまとめたカレンダーでも確認できます。共有リンクと外部カレンダーには作成者・更新者は表示されません。
下の「編集」「削除」ボタンから、それぞれの操作に進みます。

## 予定を編集する

概要の「編集」を押すと、作成時と同じ項目の編集ダイアログが開きます。内容を変えて「保存」を押すと反映されます。

<Screenshot src={editDialogShot} alt="予定の編集ダイアログ。上部に保存先サーバーと繰り返し設定、場所を含む入力欄、事前通知とメンション先の折りたたみ、下部に「削除」「キャンセル」「保存」ボタンがある" size="narrow" />

日時だけを変えたいときは、ダイアログを開かずにカレンダー上で直接操作することもできます。

- 予定を **ドラッグ** して別の日や時間帯に移動する
- 週・4日・日の表示で予定の **下端をドラッグ** して終了時刻を伸ばす・縮める

保存に失敗したときは元の位置に戻り、画面上部にエラーが表示されます。

## 予定を共有する

予定の「編集」を開き、**共有リンクをコピー** を押すと、その予定だけを閲覧できる URL を発行してコピーします。
Discord の別サーバー・DM・SNS などに貼り付けて共有できます。リンク先の閲覧にログインは不要です。
Discord や X のプレビューには、予定のタイトル・日時・サーバー名が表示されます。

- 発行・無効化ができるのは、その予定を編集できるメンバーです
- 同じ予定のリンクを再コピーしても URL は変わりません。未保存の変更は公開されず、保存すると共有ページにも反映されます
- **共有リンクを無効化** を押すか予定を削除すると、共有ページは開けなくなります。無効化後に再発行すると別の URL になります
- SNS 側が保存したプレビュー画像は、変更・無効化してもすぐに更新されない場合があります

<Callout type="warning">
リンクを知っている人は誰でも、予定のタイトル・日時・場所・説明とサーバー名を見ることができます。共有してよい内容か確認してから発行してください。
</Callout>

## 予定を削除する

概要の「削除」か、編集ダイアログの左下の「削除」を押すと確認ダイアログが出ます。「削除」を押すと予定が消えます。
削除した予定は元に戻せないので注意してください。

## 編集できる人を制限する (サーバー設定)

初期状態では、サーバーのメンバーならだれでも予定を追加・編集・削除できます。
カレンダー画面右上の **歯車アイコン** から開くサーバー設定で、次のチェックを入れて保存すると、
管理権限または指定したロールを持つメンバーが予定を変更できるようになります (閲覧はメンバー全員ができます)。

<Screenshot src={settingsShot} alt="サーバー設定ダイアログ。予定の編集制限と編集を許可するロールのチェック一覧、補足の ⓘ アイコン、Discord への通知 (通知先チャンネル・開始時刻に通知する・既定の事前通知)、外部カレンダーで購読するためのフィード URL がある" />

- 対象の権限: **管理者**、**サーバー管理**、**ロールの管理**、**メッセージの管理** のいずれか (サーバーのオーナーは常に変更できます)
- 「編集を許可するロール」で最大25件のロールを選べます。どれか1つを持っていれば編集できます。管理権限の追加は不要です
- 制限をOFFにしても選択したロールは保持されます。削除されたロールは一覧から外せます
- この制限は Discord の `/create` コマンドにも同じように効きます
- サーバー設定・通知先・フィードの管理には引き続き管理権限が必要です。編集ロールだけでは変更できません
- 同じダイアログの「外部カレンダーで購読する」については [外部カレンダーで見る](/docs/subscribe) を参照してください

<Callout>
Discord 側でメンバーの権限やロールを変えた直後は、反映まで少し時間がかかることがあります。サーバー設定ダイアログの「再読込」を押すと最新の権限で判定し直します。
</Callout>

<Callout type="warning">
制限が有効なサーバーで権限の無いメンバーがカレンダーを開くと、「新規作成」ボタンが押せず、予定をクリックしても「編集」「削除」は表示されません。
</Callout>

## 画像やPDFを添付する

予定の作成・編集画面で「ファイルを添付」から選択し、予定を保存します。作成前に選択したファイルは、予定の保存後に送信されます。
JPEG・PNG・WebP・PDFに対応し、1ファイル10MiB、1予定10件、サーバー全体1GiBまでです。

予定の詳細から添付一覧・画像プレビューを確認し、ファイルをダウンロードできます。追加・削除には予定の編集権限が必要です。
送信に失敗した場合も予定と送信済みの添付は残ります。「添付を再試行」で失敗した分を送り直してください。
画面を閉じた後は未送信のファイルを選び直してください。

公開共有リンクやDiscord通知には添付されません。予定を複製しても添付はコピーされません。
「添付ファイルは現在利用できません」と表示される場合は、サービス側で保存先が設定されていません。

## 繰り返し予定を編集・削除する

編集・削除・ドラッグ移動・長さ変更では **「この回のみ」「この回以降」** を選択します。
「この回のみ」は他の回を変えません。「この回以降」は元の開催日を基準に変更し、過去の回は変えません。

以降の条件を変えても、個別に編集・中止した回は元の開催日が新しい条件に含まれる限り保持します。
新しい条件から外れる個別編集済みの回や、添付のある回は、同じ予定IDの単発予定として残ります。
一方、**「この回以降を削除」では個別変更した回とその添付も削除**します。移動後の日時が過去でも、元の開催枠が対象範囲なら削除されます。

添付・共有リンクは各回に属します。複製すると、選んだ回の内容で単発予定を作れます。
同時に他の人がシリーズを変更した場合は保存を止めます。画面を開き直し、最新の内容を確認してください。
